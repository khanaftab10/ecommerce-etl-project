# E-commerce Sales Analytics ETL Pipeline

## Overview
This project demonstrates a beginner-friendly end-to-end ETL pipeline using Python, SQL, PostgreSQL, and Streamlit.

## Features
- Data extraction from CSV
- Data cleaning using Pandas
- Loading into PostgreSQL
- SQL analysis
- Dashboard visualization

## Tech Stack
- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- Streamlit

## How to Run
1. Install requirements
2. Create database
3. Run create_table.sql
4. Run etl_pipeline.py
5. Run Streamlit dashboard
